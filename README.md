# Recordatorios Contextuales — Actividad 2

Proyecto Android para Programación Mobile — Universidad IPP.

## Contenido
- `app/`: aplicación Android en Kotlin y Jetpack Compose.
- `build.gradle.kts`, `settings.gradle.kts`, `gradle.properties`: configuración Gradle.
- `documentacion/`: informe PDF y versión Word editable.

## Configuración del proyecto
- Android Gradle Plugin: 8.7.3
- Kotlin: 2.0.21
- JDK: 17
- Compile SDK: 35
- Min SDK: 24
- Target SDK: 35

## Funcionalidades documentadas
- Listado, creación y detalle de recordatorios.
- Componentes reutilizables y validación de formulario.
- ViewModel, UiState y StateFlow.
- Repositorio en memoria.
- Navigation Compose.

## Abrir
1. Descomprimir el paquete.
2. Abrir esta carpeta raíz desde Android Studio.
3. Esperar la sincronización de Gradle.
4. Ejecutar en un emulador o dispositivo Android.

Los datos se conservan en memoria durante la ejecución. El informe incluido distingue los prototipos de las capturas reales y señala las verificaciones pendientes. Antes de entregar, ejecutar el proyecto y reemplazar/añadir evidencias reales según la pauta.
